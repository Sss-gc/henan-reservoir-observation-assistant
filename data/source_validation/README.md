# 水库属性在线复核说明

本目录保存网页数据准备阶段使用的在线查询快照。在线资料只用于交叉核对，不直接替代项目组的水库边界。

## 核对规则

- 名称和在线定位：使用本地 SHP 自带的 `osm_id` 批量查询 OpenStreetMap Nominatim。
- 所在城市：以本地 `GS（2024）0650号` 行政区边界空间相交为基础，再与河南省公开资料核对。
- 中心点：网页定位使用面内 `representative_point`，避免普通质心落在狭长或多部件水库外。
- 面积：使用 SHP 水面几何计算 WGS84 椭球面积。公开资料中的“流域面积、库容、设计水面面积”不是同一指标，不直接覆盖。

## 公开资料

- 河南省生态环境厅《2005年河南省环境状况公报》：https://sthjt.henan.gov.cn/2006/06-05/1320614.html
- 鹤壁市政府采购网盘石头水库资料：https://zfcg.henan.gov.cn/hebi/content?infoId=1921937
- 河南省公共资源交易中心出山店水库资料：https://hnsggzyjy.henan.gov.cn/jyxx/002001/002001001/20251011/41581ad2-4fee-46b3-a16b-2e11bd301398.html
- 河南省水利厅白沙水库资料：https://slt.henan.gov.cn/2024/10-24/3077974.html
- Nominatim Lookup：https://nominatim.openstreetmap.org/lookup

## 已知差异

- 白沙水库位于禹州市与登封市交界；SHP 当前水面主体落在郑州市行政区一侧，管理资料地址为禹州市。
- 盘石头、孤石滩、故县、小浪底、丹江口等水面跨越一个以上行政区，网页使用跨区描述。
- 水面面积随水位和边界数据时相变化，不能与总库容或控制流域面积直接比较。
