# 星地同步实验助手 微信小程序

原生小程序 AppID wx19d45d426bb304d6。迁移版保留现有界面、腾讯地图、水库标记及Word下载，改用独立的私人静态数据服务，不使用CloudBase SDK、微信云函数、网站接口、网站密码或网站轨道文件。

## 功能

- 25座水库搜索、标记切换、当前/全部视野及缩放；不展示水面矢量范围。
- 独立中央气象台7天天气与七颗卫星未来30天完整覆盖/耀光预测。
- 与网页共用科学算法和水库基础资料；运行数据由小程序任务单独获取和计算。
- 当前水库和全部水库的Word下载、打开、保存或转发；沿用原Word模板。
- 独立访问口令，30天有效会话；退出后清除会话和页面数据。

## 当前部署

静态数据与轻量认证服务已部署到 https://reservoir-mini-private.s306221976.workers.dev 。该地址需在微信公众平台的“开发管理 → 开发设置 → 服务器域名”加入request合法域名，并完成手机验证。若微信后台拒绝默认域名，应接入符合微信要求的自有HTTPS域名。

迁移版尚未完成新域名保存、手机验收及体验版更新。此前已验收的1.0.0体验版仍是旧CloudBase版，不能把它的真机结果当作本次迁移已通过。新版本建议上传为1.1.0，在后台选为体验版；加入“我的小程序”的入口可以继续使用。

## 私人访问

管理员从已忽略的本机文件 .tools/mini-static-access.txt 获取口令，仅向获准研究人员提供。体验成员在登录页输入口令后进入，口令不会存进小程序、网站或公开仓库；本机只保存有效期会话。新增体验者仍先在微信公众平台添加“体验成员”，再提供口令，不再收集CloudBase访问标识。

共享口令不再逐人区分微信身份；需要撤销已分享的口令时由管理员更新服务端秘密，旧会话会失效。不能把 .tools/mini-static-secrets.json 发给体验者。

## 构建与联调

在仓库根目录运行 pnpm miniprogram:prepare 和 pnpm miniprogram:check；无需构建npm或安装CloudBase依赖。保留urlCheck=true。导入微信开发者工具、编译并预览，验证口令登录、地图、天气、过境、当前与全部Word。

生产数据与自动更新流程见 ../mini-static/README.md 。小程序工程只保留公开服务地址；不打包示例天气或过期轨道。数据更新时间不是当日时显示过期提示，失败时不回退到网站或伪造新数据。
