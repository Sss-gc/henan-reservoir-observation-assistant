# 星地同步实验助手 · 微信小程序

独立原生微信小程序，AppID 为 `wx19d45d426bb304d6`。天气和卫星过境采用网站同源真实数据，地图采用微信内置腾讯地图。不包含示例天气或内置旧轨道文件。尚未上传、审核或发布正式小程序。

## 数据与访问

| 内容 | 小程序实现 |
|---|---|
| 登录 | 使用原网站邮箱与固定密码，通过 `/api/session` 获取30天签名会话；密码不在本机保存 |
| 天气 | 登录后读取同一网站 `/api/weather?all=1`，即中央气象台7日昼夜文字预报KV缓存 |
| 轨道 | 登录后读取同一网站 `/data/orbit-passes.json`，保留原始日期、时刻、历元及耀光值 |
| 推荐 | 直接从网站TypeScript生成共享模块，按白天严格为“晴”的规则匹配 |
| 地图 | 微信内置 `<map>` 腾讯底图，基础展示无需单独申请地图Key或调用瓦片代理 |
| 水库 | 从网站GeoJSON生成25座水库边界与面积，保留内环、多库区及丹江口南侧汉江区域 |

`config.js` 中的 `apiBase` 是网站地址。天气和轨道请求附带 Bearer 签名会话，网站原有Cookie登录继续可用。网站密码及Cloudflare会话密钥不写入小程序。只在本机保存签名会话与选中的水库，不申请定位、手机号或通讯录权限。

天气不可用时清空对应天气，不生成晴天推荐；轨道不可用时不回退到旧文件。来源未更新至北京时间当日时显示提示和实际时间。网站本身缓存过旧时，小程序不会将它伪装成新数据。

## 原生腾讯地图

小程序直接使用微信内置`<map>`，支持25座水库标记、所有边界环、点击切换、拖动、双指或按钮缩放、全部水库视野与定位当前库区。本地水库搜索不调用腾讯地点检索API。当前基础功能不配置`subkey`，不使用腾讯位置服务JS SDK。

网站的底图继续使用天地图。2026-10-17小程序天地图代理多次遭上游HTTP418安全拦截，更新服务端key并重新部署后仍未恢复；用户提出使用微信内置腾讯地图，当前小程序已移除瓦片下载链路，不再依赖`TIANDITU_SERVER_KEY`。历史生产拦截编号及诊断经过保留在`docs/开发上下文记录.md`。

水库原始边界及面积继续保留WGS84。仅生成地图显示副本时转换为GCJ-02，避免与腾讯底图错位；不将转换结果用于面积或观测计算。所有边界环通过折线绘制，保留内环、多个库区和丹江口南侧汉江区域。

## 检查

在仓库根目录运行：

```powershell
pnpm miniprogram:prepare
pnpm miniprogram:check
pnpm test
pnpm typecheck:functions
pnpm build
```

`prepare` 仅生成水库基础数据和共享规则，不再打包轨道或构造天气。`check` 检查5个页面、原生地图组件、语法、模板、登录/失效、真实响应契约、失败时清空数据、网站算法一致性、GCJ-02显示坐标、完整边界及视野/标记交互。测试替身仅在检查脚本中，不属于小程序数据。

如本机存在 `.tools/miniprogram-validation/node_modules/miniprogram-compiler`，还会运行微信wcc/wcsc编译。该工具不是运行依赖。自动检查不能替代开发者工具与真机验收。
