## 数据与访问

| 内容 | 小程序实现 |
|---|---|
| 登录 | 使用原网站邮箱与固定密码，通过 `/api/session` 获取30天签名会话；密码不在本机保存 |
| 天气 | 登录后读取同一网站 `/api/weather?all=1`，即中央气象台7日昼夜文字预报KV缓存 |
| 轨道 | 登录后读取同一网站 `/data/orbit-passes.json`，保留原始日期、时刻、历元及耀光值 |
| 推荐 | 直接从网站TypeScript生成共享模块，按白天严格为“晴”的规则匹配 |
| 地图 | 天地图 `vec_w` 矢量底图与 `cva_w` 中文注记，经受保护的 `/api/map-tile` 获取 |
| 水库 | 从网站GeoJSON生成25座水库边界与面积，保留内环、多库区及丹江口南侧汉江区域 |

`config.js` 中的 `apiBase` 是网站地址。请求附带 Bearer 签名会话，网站原有Cookie登录继续可用。天地图服务端key、网站密码及Cloudflare会话密钥不写入小程序。只在本机保存签名会话与选中的水库，不申请定位、手机号或通讯录权限。

天气不可用时清空对应天气，不生成晴天推荐；轨道不可用时不回退到旧文件。来源未更新至北京时间当日时显示提示和实际时间。网站本身缓存过旧时，小程序不会将它伪装成新数据。

## 天地图服务端key（当前待配置）

联调已确认，网站现有key属于**浏览器端**，从服务端请求时天地图返回HTTP403、错误码301012“权限类型错误”。网站继续使用原浏览器端key。小程序代理单独使用服务端key：

1. 在[天地图控制台](https://console.tianditu.gov.cn/api/key)创建供此应用使用的服务端key。
2. 在Cloudflare Pages项目 `henan-reservoir-observation-assistant` 的设置中，将 `TIANDITU_SERVER_KEY` 添加为加密变量，至少配置Production；需要预览部署时也配置Preview。
3. 重新部署Pages，使新Secret绑定到运行中的函数。

没有该配置时，地图会明确提示“天地图服务端key尚未配置”，仍可查询真实天气与轨道，不会切回腾讯地图。代理仅允许两种固定图层与合法瓦片坐标，不能转发任意地址。

地图使用Web墨卡托投影直接绘制原始地理坐标，不做GCJ-02偏移，也不重新计算参考面积。支持拖动、双指或按钮缩放、水库标记选择、全部水库视野和定位当前库区，保留天地图来源标注。

## 检查

在仓库根目录运行：

```powershell
pnpm miniprogram:prepare
pnpm miniprogram:check
pnpm test
pnpm typecheck:functions
pnpm build
```

`prepare` 仅生成水库基础数据和共享规则，不再打包轨道或构造天气。`check` 检查5个页面、天地图组件、语法、模板、登录/失效、真实响应契约、失败时清空数据、网站算法一致性、地图投影与交互。测试替身仅在检查脚本中，不属于小程序数据。

如本机存在 `.tools/miniprogram-validation/node_modules/miniprogram-compiler`，还会运行微信wcc/wcsc编译。该工具不是运行依赖。自动检查不能替代开发者工具与真机验收。
