# 星地同步实验助手 微信小程序

原生工程 AppID wx19d45d426bb304d6。保留原界面、腾讯地图、水库标记及Word下载，使用独立静态数据服务，不使用CloudBase、网站接口、网站密码或网站轨道文件。按用户最新要求改为免登录，打开即可进入首页。

## 功能

- 26座水库搜索、标记切换、当前/全部视野及缩放；不展示水面矢量范围。
- 独立中央气象台7天天气及七颗卫星未来30天完整覆盖/耀光预测。
- 共用科学算法和基础资料；运行数据由小程序任务单独获取和计算。
- 当前水库和全部水库的Word下载、打开、保存或转发；沿用原模板。
- 不保存口令或会话；启动时清除旧版本会话。旧登录页链接自动转到首页。

## 部署与手机验证

静态服务使用免费GitHub Pages，地址为 `https://sss-gc.github.io/henan-reservoir-observation-assistant`。在微信公众平台的request合法域名中添加 **`https://sss-gc.github.io`**（不带仓库路径），然后在开发者工具“⋯ → 设置 → 项目设置 → 项目配置 → 域名信息”刷新，重新编译并生成新的预览二维码。保留urlCheck=true。JSON和Word都通过wx.request获取，不需添加downloadFile域名。

原workers.dev入口出现“电脑经代理200、绕过代理直连超时、手机预览timeout”的结果，因此不再作为小程序运行入口。GitHub Pages的本机直连检查不能替代手机验收；手机需检查天气、过境及当前/全部Word下载打开。

计划每日北京时间09:15开始独立生成，09:45、10:45检查当天批次并按需补跑；当天天气、轨道及文档批次已发布时跳过重复生成，手动运行始终刷新。完整批次通过GitHub Actions发布到GitHub Pages，不需要购买域名或新增部署密钥。定时触发和Pages缓存可能延迟，以页面显示的实际生成时间为准。1.1.0已设为体验版，用户已确认手机天气、过境及当前/全部水库Word下载打开四项正常；已有体验成员升级时无需重新添加。

## 访问范围

无需访问口令、CloudBase UID或微信身份登录，数据和Word地址均公开可读。体验版小程序入口仍需要微信公众平台的体验成员资格；这个资格不限制静态文件地址本身。网站的登录设置保持不变。

只在本机保存所选水库，不申请位置、手机号或通讯录权限。

## 构建与检查

在根目录执行pnpm miniprogram:prepare和pnpm miniprogram:check，无需安装CloudBase依赖或构建npm。测试覆盖免登录首次打开、旧入口跳转、错误处理、推荐判断、原生地图和两种Word下载。网络失败时显示实际错误，不跳到登录页。

运行数据不打包进小程序；实际生成时间过旧时显示过期状态，不回退网站或伪造数据。独立发布流程见 ../mini-static/README.md 。
