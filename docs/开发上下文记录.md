## 二、主要运行方式

### 一键启动

双击 `ops/windows/启动网站.bat`，然后访问：

- 网页：`http://127.0.0.1:5173/`
- 后端文档：`http://127.0.0.1:8000/docs`

### 刷新未来轨道

双击 `ops/windows/刷新卫星轨道.bat`，或者运行：

```powershell
.\.venv\Scripts\python.exe -m backend.app.tasks.refresh_orbits --days 30
```

### 刷新某座水库实际影像

```text
POST /api/v1/reservoirs/{水库ID}/products/refresh?days=90&limit_per_source=200
```

### 批量刷新25座水库

双击 `ops/windows/刷新全部影像目录.bat`，或运行：

```powershell
.\.venv\Scripts\python.exe -m backend.app.tasks.refresh_all_imagery --days 90 --limit-per-source 500
```

## 四、尚未实现或需要继续完善的功能

1. **真实Landsat像素缩略图**：USGS当前缩略图和COG直链会跳转EROS登录。页面目前显示明确标注的覆盖示意图。后续需要配置合法USGS账号/授权，或接入能覆盖当前产品时效的公开渲染服务。
2. **多瓦片自动打包**：已能下载包含全部组成瓦片和官方资产地址的JSON清单，但尚未由服务器代为下载并压缩全部原始文件；Copernicus资产仍需要用户合法授权。
3. **Landsat水库局部云量**：Sentinel-2 SCL局部云量已实现；Landsat QA_PIXEL位定义已经核准，但USGS当前数据文件访问需要授权，因此Landsat局部云量尚未自动计算。
4. **实际成像计划确认**：未来窗口只证明轨道和幅宽可以完整覆盖，未接入卫星运营方任务计划，不能视为已确认成像。
5. **国产卫星实际产品自动检索**：HJ-2B和高分一号宽幅轨道预测已实现，但国家遥感数据与应用服务平台需要账号，尚未获得公开文档化匿名产品API或项目授权凭据。
6. **生产部署**：尚未完成Nginx/HTTPS、用户权限、日志轮转、数据库备份和正式服务器部署。
